# BABAA AUTO 〜田舎のばあちゃん無双〜

限界集落を舞台にした GTA 風・見下ろし型ブラウザゲーム。
主人公はばあちゃん。回覧板を届け、草をむしり、鶏を追い、新入りにケジメをつける。

## 遊び方

`index.html` をブラウザで開くだけ（ビルド・サーバー不要、依存ライブラリなし）。

```
open index.html
```

### 操作

| キー | 動作 |
|---|---|
| `W` `A` `S` `D` / 矢印 | 移動（軽トラでは W 前進 / S ブレーキ・バック / A D ハンドル） |
| `Shift` | 早足（スタミナ消費） |
| `Space` | 話す・拾う・捕まえる・軽トラ乗降（`E` / `Enter` も可） |
| `J` / 左クリック | 杖を振る（草むしり／お参り／ケジメ。`K` `F` も可） |
| `M` | 拡大マップ |
| `P` / `Esc` | ポーズ（仕事一覧） |

移動しながら押せるよう、「調べる」は左手の親指で届く `Space` に置いている。
杖は右手の `J`。対象が射程に入ると、その頭上に `Space ○○する` と出る。

### ゲームの流れ

1. 頭に **！** が出ている村人に `Space` で話しかけて仕事を受ける
2. 画面下の赤字の指示に従う（黄色いマーカーが目的地）
3. 終わったら依頼主に戻って報告 → 報酬

全 12 件の仕事。一部は前提クリアが必要（ケジメ ← ラジオ体操、ご来光 ← お参り）。

### 村八分度（お尋ね者システム）

- 村人を杖でどつく／軽トラで轢くと **村八分度 ★** が上がる
- ★ の数だけ駐在さんが自転車で追ってくる。捕まると所持金の半分を没収
- **神社の境内**に隠れるか、時間経過で ★ は下がる
- 軽トラを高速で壁にぶつけると爆発して放り出される

## ファイル構成

```
index.html        HUD・オーバーレイ・スクリプト読み込み
css/style.css     HUD / タイトル / ポーズ画面
js/util.js        数学・衝突判定・小物ヘルパ
js/world.js       マップ定義（道路・建物・田畑・川・山）と背景の焼き込み
js/entities.js    Player / Vehicle / NPC / Critter / Item / Effect
js/missions.js    村人配置・ミッション定義・進行管理
js/render.js      ワールド描画・ミニマップ・拡大マップ
js/input.js       キーボード入力
js/game.js        メインループ・衝突・駐在さん・インタラクション・HUD 更新
```

背景（3200×2400px）は起動時にオフスクリーンキャンバスへ一度だけ描画し、
毎フレームは可視範囲だけを `drawImage` で切り出している。

## 仕事を増やすには

`js/missions.js` の `MISSION_DEFS` に足すだけ。step の型は以下：

| type | 内容 | 主なフィールド |
|---|---|---|
| `talk` | 指定の人に `Space` で話す | `who` |
| `goto` | 指定座標に入る | `pos`, `r`, `needVehicle`, `timeLimit` |
| `action` | 指定スポットで `J`（杖）を `hits` 回 | `spots[]`, `hits`, `verb` |
| `collect` | 落ちている物を全部拾う | `items[]`, `label` |
| `catch` | 動物を `n` 匹つかまえる | `kind`, `n`, `spawns[]` |
| `beat` | 指定の人を杖で `hits` 回どつく | `who`, `hits` |

最後の「依頼主に報告」ステップは自動で追加される。
座標は `js/world.js` の `SPOT` に名前付きで置いてある。
