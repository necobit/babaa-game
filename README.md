# BABAA AUTO 〜田舎のばあちゃん無双〜

限界集落を舞台にした GTA 風 3D ブラウザゲーム。
主人公はばあちゃん。回覧板を届け、草をむしり、鶏を追い、新入りにケジメをつける。

## 遊び方

`index.html` をブラウザで開くだけ（ビルド・サーバー不要）。
three.js はリポジトリに同梱しているので、ネットに繋がっていなくても動く。

```
open index.html
```

### 操作

| キー | 動作 |
|---|---|
| `←` `↑` `↓` `→` | 移動（軽トラでは `↑` 前進 / `↓` ブレーキ・バック / `←` `→` ハンドル） |
| `Shift` | 早足（スタミナ消費） |
| `E` | 話す・拾う・捕まえる・軽トラ乗降 |
| `Space` / 左クリック | 杖を振る（草むしり／お参り／ケジメ） |
| `C` | カメラ切替（向き固定 ⇄ 背後に追従） |
| `M` | 拡大マップ |
| `P` / `Esc` | ポーズ（仕事一覧） |

右手を矢印キーに置く前提の配置。早足は真隣の右 `Shift`。
右手が矢印キーに乗るぶん左手が空くので「調べる」は `E`、
杖は連打しやすい親指の `Space`。
対象が射程に入ると、その頭上に `E ○○する` と出る。

互換エイリアス: 移動 `WASD` ／ 調べる `Enter` ／ 杖 `Z` `X` `J` `K` `F`

カメラは既定で**向き固定**（矢印キーの方向が画面に対して常に一定なので迷わない）。
`C` を押すと GTA 風に**背後へ回り込む追従カメラ**になり、入力もカメラ基準
（`↑`＝正面、`←` `→` ＝横）に切り替わる。

### ゲームの流れ

1. 頭に **！** が出ている村人に `E` で話しかけて仕事を受ける
2. 画面下の赤字の指示に従う（黄色いマーカーが目的地）
3. 終わったら依頼主に戻って報告 → 報酬

全 12 件の仕事。一部は前提クリアが必要（ケジメ ← ラジオ体操、ご来光 ← お参り）。

### 村八分度（お尋ね者システム）

- 村人を杖でどつく／軽トラで轢くと **村八分度 ★** が上がる
- ★ の数だけ駐在さんが自転車で追ってくる。捕まると所持金の半分を没収
- **神社の境内**に隠れるか、時間経過で ★ は下がる
- 軽トラを高速で壁にぶつけると爆発して放り出される

### 2D ロジック＋3D 描画

ゲームロジックはすべて 2D のまま（当たり判定も経路もミッションも `x, y` の平面）。
描画のときだけワールド座標 `(x, y)` を three.js の `(x, z)` に対応させ、
高さ `y` は `terrainHeight()` から引く。おかげで 3D 化しても
当たり判定・ミッション・AI のコードは一切変えていない。

見た目はテクスチャ無しの箱・円柱・ローポリ球だけ：

- **地面** … 真上から焼いた 1 枚のキャンバス（道路・田畑・川・登山道）を
  起伏つきメッシュに貼る。山のところだけ頂点を持ち上げている
- **建物** … 壁の箱 ＋ 四角錐の屋根
- **木** … 幹の円柱 ＋ 正二十面体の葉を `InstancedMesh` で 210 本まとめて描画
- **人** … 円錐台の胴 ＋ 球の頭。**軽トラ** … 箱 4 つ ＋ 円柱のタイヤ
- **目的地** … GTA 風の黄色い光の柱
- **文字**（名前・セリフ・`E` プロンプト）… 3D 座標を画面に射影して DOM で表示。
  日本語が綺麗に出るうえ、折り返しも CSS に任せられる

## 仕事を増やすには

`js/missions.js` の `MISSION_DEFS` に足すだけ。step の型は以下：

| type | 内容 | 主なフィールド |
|---|---|---|
| `talk` | 指定の人に `E` で話す | `who` |
| `goto` | 指定座標に入る | `pos`, `r`, `needVehicle`, `timeLimit` |
| `action` | 指定スポットで `Space`（杖）を `hits` 回 | `spots[]`, `hits`, `verb` |
| `collect` | 落ちている物を全部拾う | `items[]`, `label` |
| `catch` | 動物を `n` 匹つかまえる | `kind`, `n`, `spawns[]` |
| `beat` | 指定の人を杖で `hits` 回どつく | `who`, `hits` |

最後の「依頼主に報告」ステップは自動で追加される。
座標は `js/world.js` の `SPOT` に名前付きで置いてある。
